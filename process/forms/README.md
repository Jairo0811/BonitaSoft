# Formularios

Esta carpeta contendrá la documentación, diseños y artefactos relacionados con los formularios del proceso.

## Formularios previstos

- Formulario de solicitud.
- Formulario de validación o revisión.
- Formulario de aprobación/rechazo.
- Vista o formulario de cierre.

Cada formulario debe reflejar los contratos y datos reales utilizados por el proceso.
