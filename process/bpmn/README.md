# BPMN

Aquí se almacenarán los diagramas y artefactos BPMN del proceso.

## Convención sugerida

- `as-is/`: proceso actual, si aplica.
- `to-be/`: proceso propuesto.
- `exports/`: exportaciones o respaldos del proceso modelado.

No se debe considerar definitivo ningún diagrama hasta que corresponda con la implementación ejecutable en Bonita.
