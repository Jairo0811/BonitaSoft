# Conectores e integraciones

Esta carpeta concentrará los artefactos y la documentación de integración del proceso.

## Objetivos

- Consumir al menos un servicio o API.
- Documentar entrada, salida y autenticación cuando aplique.
- Manejar respuestas exitosas y errores.
- Conservar evidencia de la integración para la demo académica.

La integración concreta se definirá después de seleccionar el proceso de negocio de la Fase 1.
