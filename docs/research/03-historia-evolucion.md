# 3. Historia y evolución de Bonita

## Origen

El proyecto Bonita tiene antecedentes anteriores a la creación de Bonitasoft. La propia compañía sitúa trabajo temprano del proyecto alrededor de **2001**, ligado al ámbito de investigación de INRIA y posteriormente a Bull. Bonitasoft fue creada en **2009** por miembros del equipo del proyecto original con el propósito de continuar y comercializar una plataforma BPM de código abierto.

## Bonita Open Solution 5

Tras la creación de Bonitasoft en 2009, se desarrolló **Bonita Open Solution 5.0**, cuyo lanzamiento público se anunció para enero de 2010. Esta generación consolidó tres piezas que siguen siendo conceptualmente importantes:

- un entorno de modelado/desarrollo;
- un portal web para los usuarios;
- un motor Java para ejecutar procesos.

## Bonita BPM 7 y Living Applications

En **2015**, Bonita 7 introdujo un cambio importante hacia las llamadas **Living Applications**, separando con mayor claridad proceso, datos y experiencia de usuario. La interfaz web pasó a tener un enfoque más desacoplado del motor, permitiendo construir aplicaciones específicas alrededor de los procesos.

## Evolución reciente

La plataforma moderna se presenta como una solución abierta y extensible para automatización y optimización de procesos. Sus componentes principales actuales son:

1. **Bonita Studio** — entorno de desarrollo.
2. **Bonita Runtime** — entorno de ejecución.
3. **Bonita Continuous Delivery (BCD)** — automatización de entrega en ediciones por suscripción.

Los proyectos actuales se integran con prácticas de ingeniería de software mediante Maven, Git, pipelines CI/CD y despliegues con contenedores. La documentación 2025.2 también muestra un modelo moderno de construcción de aplicaciones e imágenes Docker.

## Ediciones

Actualmente existe una **Community edition** y ediciones **Subscription/Enterprise**. Algunas capacidades empresariales —por ejemplo, determinadas funciones de clustering, SSO, seguridad o entrega continua— dependen de la edición contratada.

## Línea temporal resumida

```text
2001     Trabajo inicial del proyecto Bonita
  │
2009     Fundación de Bonitasoft
  │
2010     Bonita Open Solution 5.0
  │
2015     Bonita 7 + Living Applications
  │
2020s    Maven / Git / CI-CD / Docker / mayor extensibilidad
  │
2025-26  Línea Bonita 2025.2 y actualizaciones de mantenimiento
```

## Relevancia de la evolución

La evolución muestra el paso desde un BPMS centrado principalmente en modelado y ejecución hacia una plataforma para desarrollar **aplicaciones basadas en procesos**, con interfaces, datos, APIs, extensiones y automatización del ciclo de entrega.
