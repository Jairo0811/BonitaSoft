## Criterio académico

La investigación separa:

- datos documentados oficialmente por Bonita;
- arquitectura propuesta por el equipo;
- estimaciones académicas, especialmente en costos y dimensionamiento.

No se presenta como oficial ningún precio empresarial que Bonitasoft no publique como tarifa vigente.
