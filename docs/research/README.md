# Investigación

Esta carpeta concentrará la investigación del proyecto para ISO-815.

## Temas previstos

- BPM y gestión por procesos.
- BPMN 2.0.
- Bonita y Bonita Studio.
- Tareas humanas y automatizadas.
- Gateways y reglas de negocio.
- Formularios y contratos.
- Conectores e integración REST.
- Trazabilidad, auditoría y manejo de errores.

La investigación debe servir de soporte para el proceso implementado y para la presentación académica del primer parcial.
